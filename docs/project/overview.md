# Классификатор обращений в техническую поддержку

Сервис автоматически определяет категорию обращения пользователя
и направляет его соответствующей группе технической поддержки. Для
классификации используется модель машинного обучения, обученная на истории
ранее обработанных обращений.

Сервис сокращает время на ручную сортировку входящих обращений: оператор
сразу получает обращения своей группы и может исправить категорию,
если модель ошиблась.

## Основные пользователи

- **Пользователь** отправляет обращение и видит, в какую категорию оно попало.
- **Оператор поддержки** просматривает обращения своей группы и при
  необходимости исправляет категорию.

## Основные функции

- отправка обращения;
- определение категории обращения и направление его в нужную группу;
- просмотр результата классификации;
- исправление категории оператором.

## Категории обращений

| Категория | Пример обращения                             |
|-----------|----------------------------------------------|
| Оплата    | «Деньги списались, но подписка не активна»   |
| Доступ    | «Не могу войти в личный кабинет»             |
| Ошибка    | «Приложение закрывается при открытии отчёта» |
| Вопрос    | «Как экспортировать данные в Excel?»         |

## Комплект документации

1. **Описание проекта** — для всех участников команды и заказчика: даёт общее
   представление о назначении сервиса, его пользователях и функциях.
2. **Требования** — для аналитиков, разработчиков и тестировщиков: фиксирует

3. **Архитектура системы** — для разработчиков: описывает компоненты сервиса,
   их взаимодействие и путь обращения от отправки до группы поддержки.
4. **Документация API** — для разработчиков внешних систем: описывает,
   как отправить обращение и получить результат классификации.
5. **Документация ML-модели** — для ML-инженеров: описывает данные для
   обучения, категории, метрики качества и ограничения модели.
6. **Руководство пользователя** — для пользователей: объясняет, как отправить
   обращение и узнать его категорию.
7. **Руководство оператора** — для операторов поддержки: объясняет, как
   просматривать обращения группы и исправлять категорию.
