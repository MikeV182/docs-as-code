# Требования

## User Stories

### US-01. Отправка обращения

Как пользователь,
я хочу отправить обращение с описанием проблемы,
чтобы получить помощь от технической поддержки.

Критерии приёмки:

- пользователь может ввести текст обращения и отправить его;
- обращение с пустым текстом не отправляется, пользователь видит сообщение
  «Опишите проблему»;
- после отправки пользователь получает номер обращения.

### US-02. Классификация обращения

Как оператор поддержки,
я хочу, чтобы обращения автоматически распределялись по категориям,
чтобы получать только обращения своей группы и не сортировать их вручную.

Критерии приёмки:

- каждому отправленному обращению присваивается одна из категорий:
  «Оплата», «Доступ», «Ошибка» или «Вопрос»;
- обращение попадает в очередь группы, отвечающей за его категорию;
- пользователь видит присвоенную категорию в карточке обращения.

### US-03. Исправление категории

Как оператор поддержки,
я хочу исправить категорию обращения, если модель ошиблась,
чтобы обращение попало к нужной группе.

Критерии приёмки:

- оператор может выбрать другую категорию из списка;
- после исправления обращение перемещается в очередь новой группы;
- в карточке обращения отображается, что категория исправлена вручную.
