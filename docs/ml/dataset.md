# Data Sheet

## Общая информация

**Название датасета:**  
multilingual-NLI-26lang-2mil7

**Источник:**  
[Hugging Face Hub](https://huggingface.co/datasets/MoritzLaurer/multilingual-NLI-26lang-2mil7)

**Автор:**  
Moritz Laurer (MoritzLaurer)

**Назначение:**  
Обучение моделей для многоязычного NLI и zero-shot классификации. Датасет
дополняет XNLI. Это основной обучающий датасет модели из
[Model Card](model-card.md).

**Лицензия:**  
Не указано.

## Состав данных

**Объём:**  
2 730 000 пар текстов: 26 языков по 105 000 пар. На каждый язык взято
25 000 пар из MultiNLI, Fever-NLI, ANLI и WANLI и 5 000 пар из LingNLI.
Для каждого языка выбрана своя случайная выборка. Объём файлов — 932 МБ.

**Тип данных:**  
Текст: пары «посылка — гипотеза» (premise — hypothesis) с меткой логического
отношения.

**Основные поля / признаки:**

| Поле                  | Описание                                                  |
|-----------------------|-----------------------------------------------------------|
| `premise`             | Посылка, переведённая на целевой язык                     |
| `hypothesis`          | Гипотеза, переведённая на целевой язык                    |
| `premise_original`    | Исходная посылка на английском                            |
| `hypothesis_original` | Исходная гипотеза на английском                           |
| `label`               | 0 — entailment, 1 — neutral, 2 — contradiction            |

Данные разбиты на 130 частей (26 языков × 5 исходных датасетов), например
`ru_mnli`, `ru_anli`.

## Получение данных

Пары взяты из пяти английских NLI-датасетов: MultiNLI, Fever-NLI, ANLI,
WANLI, LingNLI. Затем они переведены машинным переводом на 26 языков
открытыми моделями: для русского — opus-mt, для части языков — opus-mt-tc-big
и m2m100_1.2B. Перевод занял около 100 часов на GPU A100.

## Предобработка

Описан только машинный перевод и случайная выборка пар из исходных датасетов.
Фильтрация, очистка и удаление дубликатов: не указано.

## Ограничения

**Указано автором датасета:**

- машинный перевод хуже человеческого, ошибки перевода мешают сложным задачам
  вроде NLI (для zero-shot классификации грамматические ошибки, по словам
  автора, менее важны);
- автор советует проверить качество перевода для нужного языка через
  просмотр данных на Hugging Face.

**Потенциальные ограничения для нашего проекта:**

- в датасете нет обращений в поддержку: тексты взяты из общих NLI-датасетов,
  поэтому лексика может отличаться от лексики наших обращений;
- исходные тексты англоязычные, перевод может не передавать русские
  разговорные выражения и сленг пользователей.

## Использование в проекте

Мы не обучаем модель на этом датасете: он объясняет, на каких данных модель
научилась zero-shot классификации и какие у неё могут быть слабые места.

Для оценки качества на нашей задаче нужен собственный набор: обращения
с категориями, которые назначили или подтвердили операторы (US-03). На нём
можно измерить accuracy, подобрать порог уверенности и, при необходимости,
дообучить модель.
